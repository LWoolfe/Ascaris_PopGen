## Purpose

Chromosome-level reference and genome mappability. This file archives the commands and analysis notes from the thesis/paper workflow.

## Inputs

A. suum assembly GCA_013433145.1. Source filenames and absolute HPC paths are retained in the original script blocks below.

## Workflow

## Annotated scripts

## Overview

The *Ascaris suum* reference assembly ASM1343314v1 was downloaded from GenBank/NCBI under accession **GCA_013433145.1**. The reference was restricted to the 24 chromosome-level assembled molecules, comprising 19 autosomes and five X chromosomes. Unplaced and unlocalised scaffolds were excluded.

The resulting chromosome-level reference was then:

1. indexed for read alignment using BWA;
2. indexed using samtools;
3. used to generate a GATK sequence dictionary;
4. assessed using GenMap to identify uniquely mappable regions;
5. checked for malformed, overlapping or duplicated intervals;
6. converted into a sorted and merged BED mask for downstream variant filtering.

The code blocks below are presented in the order in which the steps were performed. The GenMap calculation and subsequent QC were submitted as separate jobs, rather than as one continuous executable script.

## 1. Restriction of the reference to chromosome-level sequences

This script extracted the 19 autosomes and five X chromosomes from the complete NCBI reference assembly. It also confirmed that all 24 expected chromosome accessions were present and that sequence lengths were unchanged following extraction.

```bash
#!/usr/bin/env bash
set -euo pipefail

# ============================================================
# Build chromosome-level FASTA for Ascaris suum
#
# Source reference:
#   Assembly: ASM1343314v1
#   GenBank/NCBI accession: GCA_013433145.1
#
# Retains:
#   - Chr1–Chr19: CM024168.1–CM024186.1
#   - X1–X5:      CM024187.1–CM024191.1
#
# Excludes:
#   - unplaced scaffolds
#   - unlocalised scaffolds
#
# Quality-control checks:
#   - confirms that all 24 expected chromosomes are present;
#   - reports chromosome lengths in the source FASTA;
#   - verifies that extracted chromosome lengths match the source;
#   - confirms that the final FASTA contains 24 sequences.
#
# Outputs:
#   - Ascaris_primary_scaffolds_plus_X.fasta
#   - primary_chromosomes.txt
#   - source_chromosome_sizes.tsv
#   - extracted_chromosome_sizes.tsv
#   - Ascaris_primary_scaffolds_plus_X.fasta.fai
# ============================================================


# -----------------------------
# CONFIGURATION
# -----------------------------

# Complete NCBI reference FASTA.
#
# A FASTA may be supplied as the first command-line argument.
# If no argument is supplied, the default filename is used.
REF_FASTA="${1:-GCA_013433145.1_ASM1343314v1_genomic.fna}"

# Chromosome-level reference generated by the script.
OUT_FASTA="Ascaris_primary_scaffolds_plus_X.fasta"

# File containing the sequence accessions to retain.
CHR_LIST="primary_chromosomes.txt"


# -----------------------------
# DEPENDENCY CHECKS
# -----------------------------

# Confirm that each required program is available.
need() {
  command -v "$1" >/dev/null 2>&1 || {
    echo "❌ Missing dependency: $1" >&2
    exit 1
  }
}

need samtools
need awk


# -----------------------------
# INPUT FILE CHECK
# -----------------------------

# Stop if the complete source FASTA cannot be found.
if [[ ! -f "$REF_FASTA" ]]; then
  echo "❌ Reference FASTA not found: $REF_FASTA" >&2
  echo "Usage: $0 /path/to/GCA_013433145.1_ASM1343314v1_genomic.fna" >&2
  exit 1
fi


# -----------------------------
# CHROMOSOME ACCESSION LIST
# -----------------------------

# Write the accessions of the 19 autosomes and five X chromosomes.
#
# Only these sequence records are extracted from the complete
# reference assembly.
cat > "$CHR_LIST" <<'EOF'
CM024168.1
CM024169.1
CM024170.1
CM024171.1
CM024172.1
CM024173.1
CM024174.1
CM024175.1
CM024176.1
CM024177.1
CM024178.1
CM024179.1
CM024180.1
CM024181.1
CM024182.1
CM024183.1
CM024184.1
CM024185.1
CM024186.1
CM024187.1
CM024188.1
CM024189.1
CM024190.1
CM024191.1
EOF

echo "🧾 Chromosome list written (${CHR_LIST})"


# -----------------------------
# INDEX SOURCE FASTA
# -----------------------------

# Create a samtools FASTA index for the complete reference.
#
# The .fai file records the name, length and location of each
# sequence in the FASTA and allows selected records to be extracted.
echo "📇 Indexing source FASTA..."
samtools faidx "$REF_FASTA"


# -----------------------------
# QC 1: SOURCE CHROMOSOME SIZES
# -----------------------------

# Compare the chromosome accession list against the source FASTA
# index and record the length of each selected chromosome.
#
# Output columns:
#   1. chromosome accession
#   2. chromosome length in base pairs
echo "📊 QC: chromosome sizes in source FASTA"

awk 'NR==FNR{keep[$1]; next} $1 in keep {printf "%s\t%d\n",$1,$2}' \
  "$CHR_LIST" "${REF_FASTA}.fai" \
  | tee source_chromosome_sizes.tsv

# Confirm that all 24 expected chromosome accessions were found.
N_SRC=$(wc -l < source_chromosome_sizes.tsv)

if [[ "$N_SRC" -ne 24 ]]; then
  echo "❌ Expected 24 chromosomes in source FASTA, found $N_SRC" >&2
  exit 1
fi


# -----------------------------
# EXTRACT PRIMARY CHROMOSOMES
# -----------------------------

# Extract the 24 chromosome-level sequence records into a new FASTA.
#
# The complete NCBI reference is not modified.
echo "🧬 Extracting primary chromosomes → $OUT_FASTA"

# shellcheck disable=SC2046
samtools faidx "$REF_FASTA" $(cat "$CHR_LIST") > "$OUT_FASTA"


# -----------------------------
# INDEX EXTRACTED FASTA
# -----------------------------

# Create a samtools FASTA index for the chromosome-level reference.
samtools faidx "$OUT_FASTA"


# -----------------------------
# QC 2: EXTRACTED CHROMOSOME SIZES
# -----------------------------

# Record chromosome names and lengths from the extracted reference.
echo "📊 QC: chromosome sizes in extracted FASTA"

awk '{printf "%s\t%d\n",$1,$2}' "${OUT_FASTA}.fai" \
  | tee extracted_chromosome_sizes.tsv


# -----------------------------
# QC 3: SIZE CONSISTENCY CHECK
# -----------------------------

# Compare sequence lengths in the complete and extracted references.
#
# A mismatch would indicate that a chromosome was truncated or
# otherwise altered during extraction.
echo "🔍 QC: verifying size consistency"

join -t $'\t' \
  <(sort source_chromosome_sizes.tsv) \
  <(sort extracted_chromosome_sizes.tsv) \
| awk -F'\t' '
  {
    if ($2 != $3) {
      printf "❌ Size mismatch: %s source=%d extracted=%d\n",$1,$2,$3
      exit 1
    }
  }
  END { print "✅ All chromosome sizes match exactly." }
'


# -----------------------------
# FINAL SEQUENCE-COUNT CHECK
# -----------------------------

# Count FASTA headers and confirm that the output contains exactly
# 24 sequence records.
N_SEQ=$(grep -c "^>" "$OUT_FASTA")

[[ "$N_SEQ" -eq 24 ]] || {
  echo "❌ Output FASTA contains $N_SEQ sequences (expected 24)"
  exit 1
}


# -----------------------------
# COMPLETION MESSAGE
# -----------------------------

echo "✅ Done."
echo " - Output FASTA: $OUT_FASTA"
echo " - Source sizes: source_chromosome_sizes.tsv"
echo " - Extracted sizes: extracted_chromosome_sizes.tsv"
```


## 2. Indexing the chromosome-level reference

Different downstream programs required different index formats. BWA index files were required for read alignment, the samtools FASTA index was required for rapid sequence and interval access, and the GATK sequence dictionary was required for variant calling.

```bash
# ------------------------------------------------------------------------
# Index the chromosome-level A. suum reference
# ------------------------------------------------------------------------

# Reference:
#   Ascaris suum assembly ASM1343314v1
#   GenBank/NCBI accession: GCA_013433145.1
#
# Input:
#   Ascaris_primary_scaffolds_plus_X.fasta
#
# The reference contains:
#   - 19 autosomes;
#   - five X chromosomes;
#   - no unplaced or unlocalised scaffolds.


# -----------------------------
# BWA INDEX
# -----------------------------

# Create the BWA index required for BWA-MEM read alignment.
#
# Expected outputs:
#   Ascaris_primary_scaffolds_plus_X.fasta.amb
#   Ascaris_primary_scaffolds_plus_X.fasta.ann
#   Ascaris_primary_scaffolds_plus_X.fasta.bwt
#   Ascaris_primary_scaffolds_plus_X.fasta.pac
#   Ascaris_primary_scaffolds_plus_X.fasta.sa
bwa index Ascaris_primary_scaffolds_plus_X.fasta


# -----------------------------
# SAMTOOLS FASTA INDEX
# -----------------------------

# Create the samtools FASTA index.
#
# This command had already been run during chromosome extraction.
# Repeating it recreates the same .fai file and does not alter the
# reference sequence.
#
# Output:
#   Ascaris_primary_scaffolds_plus_X.fasta.fai
samtools faidx Ascaris_primary_scaffolds_plus_X.fasta


# -----------------------------
# GATK SEQUENCE DICTIONARY
# -----------------------------

# Create the sequence dictionary required by GATK.
#
# The dictionary records chromosome names, lengths and sequence order.
#
# Output:
#   Ascaris_primary_scaffolds_plus_X.dict
gatk CreateSequenceDictionary \
  --REFERENCE Ascaris_primary_scaffolds_plus_X.fasta
```

## 3. Generation of a uniquely mappable-region mask

GenMap was used to assess sequence mappability across the chromosome-level reference.

Mappability was calculated using:

* a k-mer length of 35 bp;
* one permitted mismatch;
* the chromosome-level reference FASTA.

Intervals with a GenMap mappability score of 1 were retained. Under the specified parameters, a score of 1 indicated that the corresponding sequence was uniquely represented in the indexed reference.

The output was converted from bedGraph format into a three-column BED file for downstream interval-based filtering.

```bash
#!/usr/bin/env bash
set -euo pipefail

# ============================================================
# Identify uniquely mappable regions of the chromosome-level
# Ascaris suum reference using GenMap.
#
# Reference:
#   Ascaris_primary_scaffolds_plus_X.fasta
#
# GenMap parameters:
#   K = 35
#     Mappability was assessed using 35-base k-mers.
#
#   MISMATCH = 1
#     K-mers were evaluated while allowing one mismatch.
#
# Positions with a GenMap score of 1 were retained.
#
# Outputs:
#   - GenMap reference index
#   - GenMap mappability bedGraph
#   - mappability_unique_K35.bedgraph
#   - mappability_unique_K35.bed
# ============================================================


# -----------------------------
# CONFIGURATION
# -----------------------------

# Chromosome-level reference FASTA.
REF="Ascaris_primary_scaffolds_plus_X.fasta"

# Length of the k-mers assessed by GenMap.
K=35

# Number of mismatches permitted when evaluating k-mer uniqueness.
MISMATCH=1

# Directory containing the GenMap reference index.
INDEX_DIR="genmap_index"

# Directory containing the GenMap mappability outputs.
OUT_DIR="genmap_out"

# Prefix used for GenMap output files.
PREFIX="${OUT_DIR}/genmap"

# Final files containing intervals with a mappability score of 1.
UNIQUE_BG="mappability_unique_K${K}.bedgraph"
UNIQUE_BED="mappability_unique_K${K}.bed"


# -----------------------------
# STEP 1: INDEX THE REFERENCE
# -----------------------------

# Build a GenMap index from the chromosome-level reference.
#
# The index allows each reference k-mer to be compared with possible
# matching locations elsewhere in the indexed reference.
echo "📇 Indexing reference for GenMap..."

genmap index \
  -F "$REF" \
  -I "$INDEX_DIR"


# -----------------------------
# STEP 2: COMPUTE MAPPABILITY
# -----------------------------

# Calculate mappability across the chromosome-level reference.
#
# -K specifies the k-mer length.
# -E specifies the permitted number of mismatches.
# -I supplies the GenMap index.
# -O specifies the output prefix.
# -bg requests bedGraph output.
echo "🧩 Computing mappability (K=${K}, mismatches=${MISMATCH})..."

mkdir -p "$OUT_DIR"

genmap map \
  -K "$K" \
  -E "$MISMATCH" \
  -I "$INDEX_DIR" \
  -O "$PREFIX" \
  -bg


# -----------------------------
# STEP 3: IDENTIFY BEDGRAPH OUTPUT
# -----------------------------

# Identify the bedGraph file generated by GenMap.
#
# Both .bedGraph and .bedgraph extensions are checked because
# filename capitalisation may differ.
BG_FILE="$(ls -1 "${PREFIX}"*.bedGraph "${PREFIX}"*.bedgraph 2>/dev/null \
  | head -n 1 || true)"

# Stop if the expected bedGraph output cannot be found.
if [[ -z "${BG_FILE}" ]]; then
  echo "❌ No bedGraph file found in ${OUT_DIR}."
  echo "Expected an output matching ${PREFIX}*.bedGraph."
  exit 1
fi

echo "📄 Using bedGraph: ${BG_FILE}"


# -----------------------------
# STEP 4: EXTRACT UNIQUE REGIONS
# -----------------------------

# Retain only intervals with a GenMap mappability score of 1.
#
# The output retains the four bedGraph columns:
#   1. chromosome
#   2. start
#   3. end
#   4. mappability score
echo "📜 Extracting uniquely mappable regions (score=1)..."

awk '$4 == 1 {print $0}' "$BG_FILE" > "$UNIQUE_BG"


# -----------------------------
# STEP 5: CONVERT BEDGRAPH TO BED
# -----------------------------

# Remove the score column to create a three-column BED file:
#   chromosome, start and end.
#
# This BED file was subsequently used to define the uniquely
# mappable regions retained during variant filtering.
echo "🔄 Converting to BED..."

awk 'BEGIN{OFS="\t"} {print $1,$2,$3}' \
  "$UNIQUE_BG" > "$UNIQUE_BED"


# -----------------------------
# STEP 6: SUMMARY STATISTICS
# -----------------------------

# Calculate the total reference length represented in the GenMap
# bedGraph.
#
# BED and bedGraph intervals use zero-based, half-open coordinates,
# so interval length is calculated as:
#   end - start
echo "📊 Summary statistics:"

GENOME_SIZE="$(awk '{sum += ($3 - $2)} END {print sum+0}' "$BG_FILE")"

# Calculate the total length assigned a mappability score of 1.
UNIQUE_SIZE="$(awk '{sum += ($3 - $2)} END {print sum+0}' "$UNIQUE_BG")"

# Calculate the percentage of the represented reference classified
# as uniquely mappable.
PCT="$(awk -v u="$UNIQUE_SIZE" -v g="$GENOME_SIZE" \
  'BEGIN {
     if (g > 0)
       printf "%.2f", (u/g)*100
     else
       print "0.00"
   }')"

echo "Genome size (covered by bedGraph): ${GENOME_SIZE} bp"
echo "Uniquely mappable (score=1):       ${UNIQUE_SIZE} bp (${PCT}%)"


# -----------------------------
# COMPLETION MESSAGE
# -----------------------------

echo "✅ Done."
echo " - Unique bedGraph: ${UNIQUE_BG}"
echo " - Unique BED:      ${UNIQUE_BED}"
```

The retained file was subsequently named:

```text
mappability_unique.bed
```

## 4. QC and merging of uniquely mappable intervals

The initial BED file was checked for malformed intervals. Intervals were then sorted and merged to prevent overlapping or adjacent records from causing bases to be counted more than once.

The total uniquely mappable length was calculated before and after merging. The final merged mask was also compared with the chromosome lengths in the FASTA index to calculate:

* the total chromosome-level reference length;
* the total uniquely mappable length;
* the genome-wide uniquely mappable fraction;
* the percentage of the reference excluded;
* the uniquely mappable fraction of each chromosome.

This was submitted as a separate SLURM job.

```bash
#!/bin/bash
#SBATCH --job-name=qc_mappability
#SBATCH --partition=shared
#SBATCH --cpus-per-task=1
#SBATCH --mem=2G
#SBATCH --time=00:10:00
#SBATCH --output=qc_mappability_%j.out
#SBATCH --error=qc_mappability_%j.err

set -eo pipefail


# ----------------------------
# PATHS
# ----------------------------

# Initial BED file containing all intervals assigned a GenMap
# mappability score of 1.
BED=/parallel_scratch/lw01165/01_Reference/mappability_unique.bed

# Directory containing the chromosome-level reference and its
# associated FASTA index.
REFDIR=/parallel_scratch/lw01165/01_Reference


# ----------------------------
# ACTIVATE CONDA ENVIRONMENT
# ----------------------------

# Activate the environment containing bedtools and the other
# command-line utilities required for QC.
source /users/lw01165/miniconda3/etc/profile.d/conda.sh
conda activate tools_env


# ----------------------------
# REPORT INPUT FILE
# ----------------------------

echo "=== QC uniquely mappable genome ==="
echo "BED file: $BED"

# Confirm that the input BED exists and report its file size.
ls -lh "$BED"
echo


# ----------------------------
# BASIC SANITY CHECK
# ----------------------------

# Check that:
#   - the start coordinate is numeric;
#   - the end coordinate is numeric;
#   - the end coordinate is greater than the start coordinate.
#
# A correctly formatted BED file should return:
#   bad_lines 0
echo "Checking for malformed intervals (expect bad_lines = 0):"

awk 'BEGIN{bad=0}
     ($2!~/^[0-9]+$/||$3!~/^[0-9]+$/||$3<=$2){bad++}
     END{print "bad_lines",bad}' "$BED"

echo


# ----------------------------
# TOTAL UNIQUELY MAPPABLE BP: RAW
# ----------------------------

# Calculate the combined length of all intervals before merging.
#
# This value could double-count bases if intervals overlap.
RAW_BP=$(awk '{s+=($3-$2)} END{print s}' "$BED")

echo "unique_mappable_bp_raw    $RAW_BP"
echo


# ----------------------------
# SORT AND MERGE INTERVALS
# ----------------------------

# Define the merged output filename.
MERGED=${BED%.bed}.merged.bed

echo "Merging intervals with bedtools..."

# Sort intervals by chromosome and coordinate, then merge
# overlapping or directly adjacent intervals.
#
# This produced the final non-overlapping mask used during
# downstream variant filtering.
bedtools sort -i "$BED" \
  | bedtools merge -i - \
  > "$MERGED"


# ----------------------------
# TOTAL UNIQUELY MAPPABLE BP: MERGED
# ----------------------------

# Calculate the uniquely mappable reference length after merging.
MERGED_BP=$(awk '{s+=($3-$2)} END{print s}' "$MERGED")

echo "unique_mappable_bp_merged $MERGED_BP"
echo


# ----------------------------
# LOCATE FASTA INDEX
# ----------------------------

# Locate the FASTA index in the reference directory.
#
# The expected file was:
#   Ascaris_primary_scaffolds_plus_X.fasta.fai
FAI=$(ls "$REFDIR"/*.fai 2>/dev/null | head -n 1 || true)


# ----------------------------
# GENOME-WIDE MAPPABILITY SUMMARY
# ----------------------------

if [[ -z "$FAI" ]]; then

  echo "WARNING: No FASTA index (.fai) found in $REFDIR"
  echo "Genome-wide fraction cannot be calculated."

else

  echo "Using FASTA index: $FAI"

  # Sum the chromosome lengths in column 2 of the FASTA index.
  GENOME_BP=$(awk '{s+=$2} END{print s}' "$FAI")

  # Report the total reference length, uniquely mappable length,
  # uniquely mappable fraction and percentage excluded.
  awk -v g="$GENOME_BP" -v u="$MERGED_BP" 'BEGIN{
    printf("genome_bp                 %d\n", g);
    printf("unique_mappable_bp        %d\n", u);
    printf("unique_mappable_fraction  %.4f\n", u/g);
    printf("percent_lost              %.2f\n", 100*(1-(u/g)));
  }'

  echo


  # ----------------------------
  # PER-CHROMOSOME SUMMARY
  # ----------------------------

  echo "Writing per-chromosome mappability table..."

  # Sum uniquely mappable interval lengths separately for each
  # chromosome.
  #
  # Temporary output columns:
  #   1. chromosome
  #   2. uniquely mappable base pairs
  awk '{m[$1]+=($3-$2)}
       END{for (c in m) print c"\t"m[c]}' "$MERGED" \
    | sort -k1,1 \
    > /tmp/uniq_bp.tsv

  # Extract chromosome names and chromosome lengths from the
  # FASTA index.
  awk '{print $1"\t"$2}' "$FAI" \
    | sort -k1,1 \
    > /tmp/chr_sizes.tsv

  # Join chromosome lengths to uniquely mappable lengths and
  # calculate the uniquely mappable fraction of each chromosome.
  #
  # Final output columns:
  #   chrom
  #   size_bp
  #   uniq_mappable_bp
  #   uniq_fraction
  join -t $'\t' /tmp/chr_sizes.tsv /tmp/uniq_bp.tsv \
    | awk -F'\t' '
        BEGIN {
          OFS="\t"
          print "chrom","size_bp","uniq_mappable_bp","uniq_fraction"
        }
        {
          print $1,$2,$3,$3/$2
        }' \
    > ${BED%.bed}_uniq_fraction_by_chr.tsv

  echo "Per-chromosome summary written to:"
  echo "  ${BED%.bed}_uniq_fraction_by_chr.tsv"
  echo

  # Display the first ten lines as an immediate output check.
  head ${BED%.bed}_uniq_fraction_by_chr.tsv
fi


# ----------------------------
# COMPLETION MESSAGE
# ----------------------------

echo
echo "QC COMPLETE"
```

## 6. Generation of 25-kb autosomal windows with ≥80%, ≥90%, and ≥95% unique mappability

**Status: original SLURM script recovered (supplied October 2026).** This is the historical `qc_25kb_mappability` job used to generate the BED of 25-kb autosomal windows with at least 90% uniquely mappable bases, which is subsequently used by the ploidy/CN workflow in [`04`](04_ploidy_CNV_and_genotype_QC.md).

**Inputs:** The full 24-chromosome 25-kb window BED `Ascaris_primary_scaffolds_plus_X.25kb.bed` is generated by the `bedtools makewindows -w 25000` script documented in [`03`](03_mapping_and_mapping_QC.md). The merged unique-mappability BED is generated earlier in this file. `autosomes19.txt` lists the 19 autosomal accession IDs. A convenience copy of the latter is supplied in `data/autosomes19.txt` (reconstructed from the documented accessions; the original HPC input file is not available).

**Outputs:** An autosome-only window BED, a per-window mappability-fraction table, and thresholded BEDs `Ascaris.autosomes19.25kb.unique80.bed`, `...unique90.bed`, `...unique95.bed`. The ≥90% file feeds the 156-sample `mosdepth` ploidy workflow.

```bash
#!/bin/bash
#SBATCH --job-name=map25kb
#SBATCH --output=qc_25kb_mappability_%j.out
#SBATCH --error=qc_25kb_mappability_%j.err
#SBATCH --time=00:30:00
#SBATCH --mem=10G
#SBATCH --cpus-per-task=2

set -eo pipefail

echo "============================================================"
echo "25-kb autosomal unique-mappability QC"
echo "Started: $(date)"
echo "Host: $(hostname)"
echo "============================================================"

# ------------------------------------------------------------
# Activate environment
# ------------------------------------------------------------
source /users/lw01165/miniconda3/etc/profile.d/conda.sh
conda activate tools_env

echo "bedtools:"
bedtools --version

# ------------------------------------------------------------
# Paths
# ------------------------------------------------------------
REFDIR="/parallel_scratch/lw01165/01_Reference"

WINDOWS="${REFDIR}/Ascaris_primary_scaffolds_plus_X.25kb.bed"
MAPPABILITY="${REFDIR}/mappability_unique.merged.bed"

# This should contain ONE autosome/chromosome ID per line
AUTOSOMES="${REFDIR}/autosomes19.txt"

OUTDIR="${REFDIR}/25kb_mappability"
mkdir -p "${OUTDIR}"

AUTO_WINDOWS="${OUTDIR}/Ascaris.autosomes19.25kb.bed"
MAP_TABLE="${OUTDIR}/Ascaris.autosomes19.25kb.mappability.tsv"

# ------------------------------------------------------------
# Check input files
# ------------------------------------------------------------
for FILE in "${WINDOWS}" "${MAPPABILITY}" "${AUTOSOMES}"
do
    if [[ ! -s "${FILE}" ]]; then
        echo "ERROR: Missing or empty file:"
        echo "${FILE}"
        exit 1
    fi
done

# ------------------------------------------------------------
# 1. Keep only the 19 autosomes
# ------------------------------------------------------------
echo
echo "Extracting autosomal 25-kb windows..."

awk '
BEGIN {OFS="	"}
NR==FNR {
    keep[$1]=1
    next
}
($1 in keep) {
    print
}
' "${AUTOSOMES}" "${WINDOWS}" > "${AUTO_WINDOWS}"

echo "Autosomal windows retained:"
wc -l "${AUTO_WINDOWS}"

# ------------------------------------------------------------
# 2. Calculate unique-mappability fraction per window
#
# bedtools coverage adds:
#   number of overlapping intervals
#   number of bases covered
#   window length
#   fraction of window covered
# ------------------------------------------------------------
echo
echo "Calculating unique-mappability fraction..."

{
    echo -e "chrom	start	end	n_unique_intervals	unique_bases	window_length	unique_fraction"

    bedtools coverage         -a "${AUTO_WINDOWS}"         -b "${MAPPABILITY}"

} > "${MAP_TABLE}"

# ------------------------------------------------------------
# 3. Create BED files at several thresholds
# ------------------------------------------------------------
for THRESH in 0.80 0.90 0.95
do

    LABEL=$(echo "${THRESH}" | sed 's/0\.//')

    awk -v t="${THRESH}" '
    BEGIN {OFS="	"}
    NR > 1 && $7 >= t {
        print $1,$2,$3
    }
    ' "${MAP_TABLE}"     > "${OUTDIR}/Ascaris.autosomes19.25kb.unique${LABEL}.bed"

done

# ------------------------------------------------------------
# 4. Summary
# ------------------------------------------------------------
echo
echo "============================================================"
echo "Mappability summary"
echo "============================================================"

TOTAL=$(wc -l < "${AUTO_WINDOWS}")

echo "Total autosomal 25-kb windows: ${TOTAL}"

for THRESH in 80 90 95
do
    N=$(wc -l < "${OUTDIR}/Ascaris.autosomes19.25kb.unique${THRESH}.bed")

    PCT=$(awk -v n="${N}" -v total="${TOTAL}"         'BEGIN {printf "%.2f", (n/total)*100}')

    echo ">= ${THRESH}% uniquely mappable: ${N} (${PCT}%)"
done

echo
echo "Outputs:"
echo "${MAP_TABLE}"
echo "${OUTDIR}/Ascaris.autosomes19.25kb.unique80.bed"
echo "${OUTDIR}/Ascaris.autosomes19.25kb.unique90.bed"
echo "${OUTDIR}/Ascaris.autosomes19.25kb.unique95.bed"

echo
echo "Finished: $(date)"
echo "============================================================"
```
